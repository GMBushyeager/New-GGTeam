# Current screens

Screenshots of the current Resourcifi app, taken from the deck
`Current_GGTeam_App_Flow.pptx` (4 slides, screens numbered 1–50).

Files are named `s<slide>-<deck number>-<section>.jpg`. The slide prefix is
needed because the deck uses numbers 27 and 28 twice (see Deck issues).
Images are iPhone captures scaled to 645 × 1398 with metadata stripped.

All screens belong to the **new assessment** flow (flow 03). The deck has no
screens for sign-in, the client list or profile, assessment history, the AI
brief, reassessment or settings.

## Deck issues

1. Numbers 27 and 28 are used twice: Goals / Preferences on slide 2 and Body
   Assessment on slide 3.
2. Screens 2 and 4 are the same image (Medical History: pacemaker and BP).
3. Screens 1 and 48 were embedded at low resolution (369 × 800) in the deck.
4. The second Goals / Preferences screen (28) and the Body Assessment screens
   start mid-scroll, so some fields between them may be missing (for example,
